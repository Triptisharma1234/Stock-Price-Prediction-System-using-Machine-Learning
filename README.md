# Stock-Price-Prediction-System-using-Machine-Learning
# 📈 AI FinTech Analytics Platform

### AI-Powered Stock Forecasting & Market Intelligence Dashboard

An advanced **Stock Market Analysis and Forecasting Platform** built using **Python, Streamlit, Machine Learning, and Deep Learning**.  
The system combines **technical analysis, predictive modeling, and real-time financial news integration** to provide intelligent market insights and future stock trend forecasting.

Designed as a **Final Year CSE Project (2026)**, this platform demonstrates the practical application of **Artificial Intelligence in Financial Technology (FinTech)**.

# 🧠 LSTM Model Architecture

The prediction engine is powered by a **Long Short-Term Memory (LSTM)** neural network optimized for financial time-series forecasting.

### Model Configuration
- Lookback Window: **100 Days**
- Optimizer: **Adam**
- Loss Function: **Mean Squared Error (MSE)**
- Validation Split: **10%**
- Epochs: **20**

### Why LSTM?
LSTM networks are highly effective for sequential financial data because they:
- retain temporal memory
- learn long-term dependencies
- capture market trend patterns
- improve forecasting accuracy
